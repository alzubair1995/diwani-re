# diwani-re

قناة التحديثات الرسمية لتطبيق **ديوني (Diwani)**.

هذا المستودع لا يحتوي على الكود المصدري للتطبيق — فقط بيانات الإصدارات
(`version.json`) وملفات APK كمرفقات ضمن [Releases](../../releases).

التطبيق يتحقق تلقائياً من `version.json` عند كل تشغيل لمعرفة توفر تحديث
جديد.

الكود المصدري خاص وغير منشور هنا.
